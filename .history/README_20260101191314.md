# sabaCRM

A comprehensive, modern CRM system built with Next.js 14, TypeScript, and Prisma. Designed for managing clients, teams, sales operations, and customer relationships with advanced features including role-based access control, analytics, task management, and reporting.

![Prisma](https://img.shields.io/badge/Prisma-5.19-2D3748)
![Tailwind CSS](https://img.shields.io/badge/Tailwind-3.4-38B2AC)

## 🚀 Features

### Core Structure
- **Organizational Hierarchy**: Three-level structure (Office → Department → Desk)
- **User Management**: Complete user CRUD with role-based access control
- **Permission System**: Hierarchical data access based on organizational structure and user roles
- **Role-Based Access Control (RBAC)**: Four distinct roles with granular permissions

### Client Management
- **Complete CRUD Operations**: Create, read, update, and delete clients
- **Comprehensive Client Fields**:
  - Registration Date, Client ID, Name, Country
  - Email, Phone, Affiliate, Affiliate Source
  - Sales Status (18 predefined statuses)
  - Sales Team & Sales Rep assignments
  - Retention Team & Retention Rep assignments
  - FTD Date, Balance, Notes
- **Client Notes**: Add and manage notes for each client
- **Status History**: Track all status changes with timestamps and user information
- **Communication History**: Record and view all client communications (calls, emails, notes, meetings)
- **Client Detail View**: Comprehensive client profile with all information and history

### Advanced Features

#### Search & Filtering
- **Full-Text Search**: Real-time search across client names, emails, phones, and IDs
- **Advanced Filtering**: Multi-criteria filtering system with:
  - Status filtering
  - Country filtering
  - Sales/Retention Rep filtering
  - Desk filtering
  - Affiliate filtering
  - Date range filtering
- **Search Autocomplete**: Instant search suggestions as you type

#### Bulk Operations
- **Bulk Update**: Update multiple clients simultaneously
- **Bulk Assign**: Assign clients to teams/reps in bulk
- **Bulk Delete**: Delete multiple clients with permission checks
- **Select All**: Quick selection of all visible clients

#### Import/Export
- **CSV Export**: Export client data to CSV format
- **Excel Export**: Export client data to Excel format
- **CSV Import**: Import clients from CSV files
- **Excel Import**: Import clients from Excel files
- **Validation**: Data validation during import with error reporting

#### Duplicate Detection
- **Automatic Detection**: System automatically detects potential duplicate clients
- **Confidence Scoring**: Each duplicate match includes a confidence percentage
- **Merge Functionality**: Merge duplicate clients while preserving all data
- **Dismiss Option**: Dismiss false positive duplicates

#### Activity Logging
- **Comprehensive Audit Trail**: Track all system activities
- **User Actions**: Log create, update, delete, and assign actions
- **Filtering**: Filter logs by user, client, activity type, and date
- **Pagination**: Efficient pagination for large log datasets

#### Dashboard & Analytics
- **Key Performance Indicators (KPIs)**:
  - Total Clients
  - Converted Clients
  - Total Balance
  - Conversion Rate
- **Charts & Visualizations**:
  - Status Distribution Bar Chart
  - Status Overview Pie Chart
- **Role-Based Views**: Dashboard adapts based on user permissions
- **Real-Time Updates**: Statistics update automatically

#### Notifications
- **Real-Time Notifications**: Notification system with polling
- **Notification Bell**: Header notification indicator with unread count
- **Notification Center**: Dedicated page to view all notifications
- **Mark as Read**: Individual and bulk mark-as-read functionality
- **Notification Types**: Task assignments, system alerts, and more

#### Tasks & Reminders
- **Task Management**: Create, assign, and track tasks
- **Task Statuses**: PENDING, IN_PROGRESS, COMPLETED, CANCELLED
- **Priority Levels**: LOW, MEDIUM, HIGH, URGENT
- **Task Reminders**: Set reminders for tasks with date/time
- **Client Association**: Link tasks to specific clients
- **User Assignment**: Assign tasks to team members

#### Reporting
- **Custom Reports**: Create custom reports with configurable filters
- **Report Templates**: Pre-built report templates
- **Report Scheduling**: Schedule reports to run automatically (Daily, Weekly, Monthly)
- **Excel Export**: Export reports to Excel format
- **Report History**: View and manage scheduled reports

#### Email Integration
- **Email Templates**: Create and manage email templates
- **Send Emails**: Send emails directly from the CRM
- **Email Logs**: Track all sent emails with status
- **Template Reuse**: Use templates when composing emails

#### API Access
- **RESTful API**: External API for integrations
- **API Key Management**: Create, manage, and revoke API keys
- **Rate Limiting**: 100 requests per minute per API key
- **Authentication**: Secure API key-based authentication
- **API Logs**: Track all API usage

#### User Management (Admin Only)
- **User CRUD**: Create, read, update, and delete users
- **Role Assignment**: Assign roles to users
- **Organizational Assignment**: Assign users to offices, departments, and desks
- **User Profile Management**: Users can update their own profiles

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone <repository-url>
cd sabaCRM
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Environment Setup

Create a `.env` file in the root directory:

```env
# Database (SQLite - default for development)
DATABASE_URL="file:./prisma/dev.db"

# For PostgreSQL (production)
# DATABASE_URL="postgresql://user:password@localhost:5432/sabacrm?schema=public"

# NextAuth Configuration
NEXTAUTH_URL="http://localhost:3000"
NEXTAUTH_SECRET="your-secret-key-here-generate-with-openssl-rand-base64-32"

# Email Configuration (Optional)
SMTP_HOST="smtp.gmail.com"
SMTP_PORT=587
SMTP_USER="your-email@gmail.com"
SMTP_PASSWORD="your-app-password"
SMTP_FROM="noreply@sabacrm.com"
```

**Generate NEXTAUTH_SECRET:**
```bash
# On Linux/Mac
openssl rand -base64 32

# On Windows (PowerShell)
[Convert]::ToBase64String((1..32 | ForEach-Object { Get-Random -Maximum 256 }))
```

### 4. Database Setup

#### For SQLite (Default - Development)
```bash
# Generate Prisma Client
npm run db:generate

# Push schema to database
npm run db:push
```

#### For PostgreSQL (Production)
1. Create a PostgreSQL database:
```sql
CREATE DATABASE sabacrm;
```

2. Update `.env` with PostgreSQL connection string

3. Run migrations:
```bash
npm run db:generate
npm run db:push
# OR use migrations
npm run db:migrate
```

### 5. Create Initial Users

#### Create Admin User
```bash
npm run create-admin
```

Default admin credentials:
- Email: `admin@sabacrm.com`
- Password: `admin123`

#### Create Test Users (All Roles)
```bash
npm run create-test-users
```

This creates 4 test users:
- **Admin**: `admin@test.com` / `admin123`
- **Executive**: `executive@test.com` / `executive123`
- **Team Leader**: `teamleader@test.com` / `teamleader123`
- **Manager**: `manager@test.com` / `manager123`

### 6. Start Development Server

```bash
npm run dev
```

The application will be available at [http://localhost:3000](http://localhost:3000)

**Note**: The dev server runs on `0.0.0.0` by default, making it accessible on your local network.

### 7. Access the Application

1. Navigate to [http://localhost:3000](http://localhost:3000)
2. Click "Sign In" or go to `/auth/login`
3. Log in with one of the created accounts
4. Start using the CRM!

## 👥 User Roles & Permissions

### Admin
- **Full System Access**: Can view and manage all data
- **User Management**: Create, edit, and delete users
- **API Key Management**: Create and manage API keys
- **Duplicate Management**: Access duplicate detection and merge
- **All Client Data**: Can view and edit all clients regardless of assignment
- **System Configuration**: Full access to all settings

### Executive
- **Own Data Only**: Can only view clients assigned to them
- **Limited Access**: Cannot access admin features
- **Client Management**: Can manage assigned clients
- **Task Management**: Can view and manage assigned tasks
- **Reports**: Can create and view own reports

### Team Leader
- **Team Data Access**: Can view data for team members (same desk)
- **Team Management**: Can view team member information
- **Client Access**: Can view clients assigned to team members
- **Task Assignment**: Can assign tasks to team members

### Manager
- **Department/Desk Access**: Can view all data within their department or desk
- **Team Oversight**: Can view all users and clients in their department/desk
- **Reporting**: Can generate reports for their department/desk
- **User Assignment**: Can update user assignments within their scope

## 🔌 API Documentation

### Authentication

All API routes (except `/api/auth/*`) require authentication via NextAuth session cookies.

### Internal API Endpoints

#### Clients
- `GET /api/clients` - List clients (with pagination and filters)
- `POST /api/clients` - Create new client
- `GET /api/clients/[id]` - Get client details
- `PATCH /api/clients/[id]` - Update client
- `DELETE /api/clients/[id]` - Delete client
- `POST /api/clients/bulk` - Bulk update clients
- `DELETE /api/clients/bulk` - Bulk delete clients
- `POST /api/clients/filter` - Filter clients
- `GET /api/clients/export` - Export clients (CSV/Excel)
- `POST /api/clients/import` - Import clients
- `GET /api/clients/duplicates` - Get duplicate clients
- `POST /api/clients/merge` - Merge duplicate clients

#### Tasks
- `GET /api/tasks` - List tasks
- `POST /api/tasks` - Create task
- `PATCH /api/tasks/[id]` - Update task
- `POST /api/tasks/[id]/reminders` - Create task reminder

#### Reports
- `GET /api/reports` - List reports
- `POST /api/reports` - Create report
- `POST /api/reports/[id]/run` - Run report
- `GET /api/reports/[id]/schedules` - Get report schedules
- `POST /api/reports/[id]/schedules` - Create schedule

#### Users
- `GET /api/users` - List users (filtered by permissions)
- `POST /api/users` - Create user (Admin only)
- `PATCH /api/users/[id]` - Update user (Admin only)
- `DELETE /api/users/[id]` - Delete user (Admin only)

### External API (v1)

The system provides a REST API at `/api/v1/` for external integrations.

#### Authentication
- **Method**: API Key in header
- **Header**: `X-API-Key: your-api-key-here`
- **Rate Limit**: 100 requests per minute per API key

#### Endpoints
- `GET /api/v1/clients` - List clients (with filters)
- `POST /api/v1/clients` - Create client
- `GET /api/v1/clients/[id]` - Get client details
- `PATCH /api/v1/clients/[id]` - Update client

#### Example Request
```bash
curl -X GET "http://localhost:3000/api/v1/clients" \
  -H "X-API-Key: your-api-key-here"
```

### Webhooks

- `POST /api/webhooks/squaretalk` - Squaretalk webhook handler (placeholder)

## 🐛 Troubleshooting

### Database Connection Issues
- Check your `DATABASE_URL` in `.env`
- Ensure database server is running (for PostgreSQL)
- Verify database credentials

### Authentication Issues
- Ensure `NEXTAUTH_SECRET` is set in `.env`
- Check `NEXTAUTH_URL` matches your server URL
- Clear browser cookies and try again

### Build Errors
- Delete `node_modules` and `.next` folders
- Run `npm install` again
- Run `npm run db:generate`

### Port Already in Use
- Change port: `PORT=3001 npm run dev`
- Or kill the process using port 3000
