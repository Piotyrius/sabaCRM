# sabaCRM

A comprehensive CRM system built with Next.js, TypeScript, Prisma, and PostgreSQL.

## Features

### Core Structure
- **Organizational Hierarchy**: Office → Department → Desk structure
- **User Management**: Role-based access control (Admin, Executive, Team Leader, Manager)
- **Permission System**: Hierarchical data access based on organizational structure

### Client Management
- Complete CRUD operations for clients
- All required fields: Registration Date, ID, Name, Country, Email, Phone, Affiliate, Affiliate Source, Sales Status (18 statuses), Sales/Retention Teams & Reps, FTD Date, Balance, Notes
- Client notes and status history tracking
- Communication history timeline

### Advanced Features
- **Search**: Full-text search with autocomplete
- **Filtering**: Advanced multi-criteria filtering system
- **Bulk Operations**: Bulk update, assign, and delete with permission checks
- **Import/Export**: CSV and Excel import/export with validation
- **Duplicate Detection**: Automatic duplicate detection and merge functionality
- **Activity Logging**: Comprehensive audit trail
- **Dashboard & Analytics**: Charts, KPIs, and role-based views
- **Notifications**: Real-time notification system
- **Tasks**: Task management with scheduling and reminders
- **Reporting**: Report builder with templates
- **API Access**: RESTful API with authentication and rate limiting
- **Email Integration**: Email sending with templates and tracking
- **Squaretalk Integration**: Placeholder for call integration

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Database**: PostgreSQL
- **ORM**: Prisma
- **Authentication**: NextAuth.js
- **UI**: Tailwind CSS, shadcn/ui
- **Charts**: Recharts
- **Search**: Fuse.js
- **Email**: Nodemailer

## Getting Started

### Prerequisites
- Node.js 18+
- PostgreSQL database
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Set up environment variables:
Create a `.env` file with:
```
DATABASE_URL="postgresql://user:password@localhost:5432/sabacrm?schema=public"
NEXTAUTH_URL="http://localhost:3000"
NEXTAUTH_SECRET="your-secret-key-here"
SMTP_HOST="smtp.gmail.com"
SMTP_PORT=587
SMTP_USER="your-email@gmail.com"
SMTP_PASSWORD="your-app-password"
SMTP_FROM="noreply@sabacrm.com"
```

3. Set up the database:
```bash
npx prisma generate
npx prisma db push
```

4. Run the development server:
```bash
npm run dev
```

5. Open [http://localhost:3000](http://localhost:3000)

## API Documentation

### Authentication
All API routes (except auth) require authentication via NextAuth session.

### External API
The system provides a REST API at `/api/v1/` for external integrations:
- Authentication: `X-API-Key` header
- Rate Limit: 100 requests per minute
- Endpoints:
  - `GET /api/v1/clients` - List clients
  - `POST /api/v1/clients` - Create client

### Webhooks
- `POST /api/webhooks/squaretalk` - Squaretalk webhook handler

## Roles & Permissions

- **Admin**: Full access to all data
- **Executive**: Only own client data
- **Team Leader**: Team members' data (same desk)
- **Manager**: Desk/Department data
